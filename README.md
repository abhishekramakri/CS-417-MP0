MP0: The Room

GitHub Repository:
https://github.com/abhishekramakri/CS-417-MP0

Notes:
- Project was developed on macOS.
- VR controller bindings were implemented using OpenXR and InputActionReference.
- Keyboard bindings were used for development and testing due to lack of admin permissions on EWS machines.
- The same actions are bound to VR controllers and will function in a headset without code changes.
- BreakOut toggles between inside and outside view; an outside platform is used as the external vantage point.
